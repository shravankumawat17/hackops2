# 🎨 HackOps Frontend Design System & Agent Directives

> 🚨 **MANDATORY INSTRUCTIONS FOR CODING HARNESSES / AI AGENTS:**  
> Before building any frontend screen or importing components, you **MUST** read and follow:
> 
> 👉 [**`AGENT_FRONTEND_PROTOCOL.md`**](file:///c:/hackathon/hackops/AGENT_FRONTEND_PROTOCOL.md)
> 
> **Key Rules:**
> 1. **Do not dump all components at once**: The component catalog is a parts warehouse. Choose only **3 to 6 components** that directly serve the product's MVP.
> 2. **No hardcoded Watermelon yellow/black colors**: Re-skin all imported components using standard Tailwind semantic tokens (`bg-background`, `text-foreground`, `border-border`, `bg-primary`).
> 3. **Pick or confirm the theme first**: Reference the 4 curated presets in [`design-system/themes.json`](file:///c:/hackathon/hackops/design-system/themes.json) (Neo-Agentic Indigo, Cyber Emerald, Monochrome Noir, Electric Violet).
> 4. **Follow the Decision Matrix**: Refer to Section 3 in `AGENT_FRONTEND_PROTOCOL.md` to match the exact archetype of the hackathon problem statement.
