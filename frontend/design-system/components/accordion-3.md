# Accordion 3 (`Accordion3`)

Clean Shadcn-styled FAQ/Collapsible accordion with custom icon markers and chevron rotations from Watermelon UI.

- **Source Code**: [`accordion-3.tsx`](./accordion-3.tsx)
- **Install Command**:
  ```bash
  pnpm dlx shadcn@latest add https://registry.watermelon.sh/r/accordion-3.json
  ```
- **Dependencies**: `lucide-react, @radix-ui/react-accordion (or standard shadcn accordion primitives)`

---

## Features
- Accessible collapsible drawer states
- Custom left icon badges per item
- Smooth chevron indicator rotation
- Clean typography and muted foreground content

---

## Source & Import

```tsx
import Accordion3 from "@/components/ui/accordion-3";
```
