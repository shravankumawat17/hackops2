# Adaptive Slider (`AdaptiveSlider`)

Haptic-inspired interactive slider with animated numerical bubbles, dynamic fill gradients, and spring responsiveness.

- **Source Code**: [`adaptive-slider.tsx`](./adaptive-slider.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/adaptive-slider.json
  ```
- **Dependencies**: `motion (or framer-motion)`

---

## Features
- Adaptive floating thumb with live numeric readout
- Fluid spring physics with motion/react
- Dynamic track fill width
- Haptic feedback friendly interaction

---

## Source & Import

```tsx
import AdaptiveSlider from "@/components/ui/adaptive-slider";
```
