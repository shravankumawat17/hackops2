# Alert 10 (`Alert10`)

Interactive banner/toast alert with close dismissal, leading status icon, and rich description typography.

- **Source Code**: [`alert-10.tsx`](./alert-10.tsx)
- **Install Command**:
  ```bash
  pnpm dlx shadcn@latest add https://registry.watermelon.sh/r/alert-10.json
  ```
- **Dependencies**: `react-icons (RxCross2), @radix-ui or shadcn alert primitives`

---

## Features
- Dismissible with exit state
- Supports leading status badges and icons
- Accessible screen-reader markup (sr-only close label)
- Subtle border and background theming

---

## Source & Import

```tsx
import Alert10 from "@/components/ui/alert-10";
```
