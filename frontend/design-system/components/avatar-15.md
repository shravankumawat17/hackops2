# Avatar Stack (`Avatar15`)

Stacked overlapping team avatars with tooltip details and remaining count badge from Watermelon UI.

- **Source Code**: [`avatar-15.tsx`](./avatar-15.tsx)
- **Install Command**:
  ```bash
  pnpm dlx shadcn@latest add https://registry.watermelon.sh/r/avatar-15.json
  ```
- **Dependencies**: `Avatar primitives (Shadcn/Radix)`

---

## Features
- Overlapping avatar stack layout
- Clean ring borders with theme background
- Fallback initials when image fails
- Scalable user profile array

import Avatar15 from "@/components/ui/avatar-15";
