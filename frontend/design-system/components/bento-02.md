# Bento Grid 02 (`Bento2`)

High-polish interactive bento grid featuring a live dynamic map card, analytics preview, and smooth motion transitions from Watermelon UI.

- **Source Code**: [`bento-02/index.tsx`](./bento-02/index.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/bento-02.json
  ```
- **Dependencies**: `motion`

---

## Features
- Interactive location map card with custom pins and motion hover
- Tactile bevel inset shadows in dark and light modes
- Responsive multi-span card layout
- Smooth layout transitions with motion/react

---

## Source & Import

```tsx
import Bento2 from "@/components/ui/bento-02";
```
