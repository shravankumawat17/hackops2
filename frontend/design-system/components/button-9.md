# Loading Button (`Button9`)

Disabled/in-progress button with 3 staggered bouncing dot indicators from Watermelon UI.

- **Source Code**: [`button-9.tsx`](./button-9.tsx)
- **Install Command**:
  ```bash
  pnpm dlx shadcn@latest add https://registry.watermelon.sh/r/button-9.json
  ```
- **Dependencies**: `Button primitives (Shadcn/Radix)`

---

## Features
- Built-in 3-dot staggered wave bounce animation
- Disabled pointer-events during loading
- Zero extra animation libraries (pure Tailwind animate-bounce)
- Clean inline flex alignment

---

## Source & Import

```tsx
import Button9 from "@/components/ui/button-9";
```
