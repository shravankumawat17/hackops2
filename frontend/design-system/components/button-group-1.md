# Split Action Button Group (`ButtonGroup1`)

Split button group pairing a primary action button (e.g. Upload) with an adjacent count badge pill from Watermelon UI.

- **Source Code**: [`button-group-1.tsx`](./button-group-1.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/button-group-1.json
  ```
- **Dependencies**: `lucide-react, Button primitives`

---

## Features
- Segmented joined border styling
- Action label with Lucide icon
- Secondary status counter label
- Interactive hover and active states

---

## Source & Import

```tsx
import ButtonGroup1 from "@/components/ui/button-group-1";
```
