# Toolbar Button Group (`ButtonGroup12`)

Connected segmented toolbar button group for switching controls, views, or workspaces from Watermelon UI.

- **Source Code**: [`button-group-12.tsx`](./button-group-12.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/button-group-12.json
  ```
- **Dependencies**: `lucide-react, Button primitives`

---

## Features
- Seamless connected button group edges
- Icon and label pairings (Controls, Projects, Insights)
- Responsive flex layout
- Clean dark/light theme integration

---

## Source & Import

```tsx
import ButtonGroup12 from "@/components/ui/button-group-12";
```
