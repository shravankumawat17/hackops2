# Card & Bento Grid Components

Catalog of card and bento grid layout components for feature showcases, architectures, and data displays.

### Available Grids & Bento Layouts
1. [**AgentBentoGrid**](./agent-bento-grid.md)
   - Code: [`agent-bento-grid.tsx`](./agent-bento-grid.tsx)
   - Purpose: Designed specifically for AI agent workspaces (Multi-agent orchestration, model playground, activity log stream, vector search knowledge base, tool telemetry).
2. [**ResearchBentoGrid**](./research-bento-grid.md)
   - Code: [`research-bento-grid.tsx`](./research-bento-grid.tsx)
   - Purpose: Tech-stack ecosystem showcase, dynamic pricing calculator card, and pause/resume sprint card.
3. [**StaggeredGrid**](./staggered-grid.md)
   - Code: [`staggered-grid.tsx`](./staggered-grid.tsx)
   - Purpose: GSAP ScrollTrigger masonry grid that transitions into an interactive bento layout.
4. [**ExpandableBentoGrid**](./expandable-bento-grid.md)
   - Code: [`expandable-bento-grid.tsx`](./expandable-bento-grid.tsx)
   - Purpose: Click-to-expand feature tiles with layout animations, ideal for "Why Us" or deep-dive features.

5. [**CardSplitAccordion (Watermelon UI)**](./card-split-accordian.md)
   - Code: [`card-split-accordian.tsx`](./card-split-accordian.tsx)
   - Install: `npx shadcn@latest add https://registry.watermelon.sh/r/card-split-accordian.json`
   - Purpose: Tactile card stack accordion where opening an item pulls it out of the stack with dynamic corner radius morphing and measured height transitions.
