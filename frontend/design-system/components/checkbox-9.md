# Icon Card Checkbox Group (`Checkbox9`)

Card-style multi-select checkboxes with category icons, subtle border highlights, and accessible labels from Watermelon UI.

- **Source Code**: [`checkbox-9.tsx`](./checkbox-9.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/checkbox-9.json
  ```
- **Dependencies**: `lucide-react, Checkbox & Label primitives`

---

## Features
- Card-styled clickable checkbox containers
- Leading category icons (Planning, Design, Operations)
- Accessible keyboard focus and Radix primitives
- Active border highlight when checked

---

## Source & Import

```tsx
import Checkbox9 from "@/components/ui/checkbox-9";
```
