# Collapsible File Tree (`Collapsible2`)

Collapsible folder and file hierarchy with chevron toggles, folder open/close state icons, and indented children from Watermelon UI.

- **Source Code**: [`collapsible-2.tsx`](./collapsible-2.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/collapsible-2.json
  ```
- **Dependencies**: `lucide-react, Collapsible primitives`

---

## Features
- Folder expand/collapse with chevron indicator rotation
- Dynamic folder open vs closed icon states
- Nested indentation lines for directory hierarchies
- File node click handlers

---

## Source & Import

```tsx
import Collapsible2 from "@/components/ui/collapsible-2";
```
