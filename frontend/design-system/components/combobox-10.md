# Multi-Select Tag Combobox (`Combobox10`)

Searchable multi-select combobox with removable badge tags, popover menu, and keyboard navigation from Watermelon UI.

- **Source Code**: [`combobox-10.tsx`](./combobox-10.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/combobox-10.json
  ```
- **Dependencies**: `lucide-react, Badge, Command, Popover primitives`

---

## Features
- Multiple tag selection with removable "x" buttons
- Searchable command filter list inside popover
- Accessible label and trigger with ChevronsUpDown
- Empty search results state

---

## Source & Import

```tsx
import Combobox10 from "@/components/ui/combobox-10";
```
