# Single-Select Combobox (`Combobox5`)

Searchable single-select dropdown with checkmark indicators, popover positioning, and keyboard arrow navigation from Watermelon UI.

- **Source Code**: [`combobox-5.tsx`](./combobox-5.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/combobox-5.json
  ```
- **Dependencies**: `lucide-react, Command, Popover primitives`

---

## Features
- Live search filtering across option items
- Selected item checkmark indicator
- Popover trigger with auto-width matching
- Accessible Radix Command / Popover primitives

---

## Source & Import

```tsx
import Combobox5 from "@/components/ui/combobox-5";
```
