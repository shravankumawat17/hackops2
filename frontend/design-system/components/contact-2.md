# Contact Form Section (`Contact2`)

Full-featured contact card with selectable contact channel badges (Email, Slack, Phone), form validation, and message input from Watermelon UI.

- **Source Code**: [`contact-2.tsx`](./contact-2.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/contact-2.json
  ```
- **Dependencies**: `lucide-react, react-icons, Card, Input, Label, Textarea primitives`

---

## Features
- Interactive contact channel pills with active states
- Clean typography and form fields with icon adornments
- Full card layout ready for landing pages or support portals
- Responsive full-width mobile and desktop layout

---

## Source & Import

```tsx
import Contact2 from "@/components/ui/contact-2";
```
