# Edit Profile Modal (`EditProfile`)

Slide-over / drawer modal for user profile management, avatar updates, social links, and form validation.

- **Source Code**: [`edit-profile.tsx`](./edit-profile.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/edit-profile.json
  ```
- **Dependencies**: `motion, lucide-react`

---

## Features
- Avatar image upload placeholder with preview
- Clean input fields for name, handle, bio, and URL
- Smooth entrance and exit spring transitions
- Save and cancel callback actions

---

## Source & Import

```tsx
import EditProfile from "@/components/ui/edit-profile";
```
