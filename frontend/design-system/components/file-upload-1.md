# File Upload & Queue Card (`FileUpload1`)

Drag-and-drop file uploader card with multi-file queue, live upload progress bars, file type icons, and remove actions from Watermelon UI.

- **Source Code**: [`file-upload-1.tsx`](./file-upload-1.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/file-upload-1.json
  ```
- **Dependencies**: `lucide-react, react-icons, Progress, Card, Badge primitives`

---

## Features
- Drag and drop upload trigger zone
- Individual file upload progress bars
- File format icons for PDFs, images, archives, code files
- Status badges (Uploading, Completed, Failed)

---

## Source & Import

```tsx
import FileUpload1 from "@/components/ui/file-upload-1";
```
