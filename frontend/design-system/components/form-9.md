# Newsletter & Auth Form (`Form9`)

Single-input newsletter or quick sign-up form with Zod email validation, tactile inset styling, and Sonner toast alerts from Watermelon UI.

- **Source Code**: [`form-9.tsx`](./form-9.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/form-9.json
  ```
- **Dependencies**: `@hookform/resolvers, react-hook-form, zod, sonner, react-icons`

---

## Features
- Zod email validation with real-time error states
- Subtle 3D inner bevel shadows
- Prefix mail envelope icon
- Sonner toast notification on successful submission

---

## Source & Import

```tsx
import Form9 from "@/components/ui/form-9";
```
