# Input & Search Components

Catalog of input fields, command palettes, and search components.

### Available Inputs
1. [**GooeySearch (VengeanceUI)**](./gooey-search.md)
   - Code: [`gooey-search.tsx`](./gooey-search.tsx)
   - Install: `npx shadcn@latest add https://raw.githubusercontent.com/Ashutoshx7/VengeanceUI/main/public/r/gooey-search.json`
   - Highlights: Morphing search pill, organic SVG metaball droplet results, debounced async/static search, Framer Motion springs.

2. [**SearchModal / Command Palette (VengeanceUI)**](./search-modal.md)
   - Code: [`search-modal.tsx`](./search-modal.tsx)
   - Install: `npx shadcn@latest add https://raw.githubusercontent.com/Ashutoshx7/VengeanceUI/main/public/r/search-modal.json`
   - Highlights: Global `⌘K`/`Ctrl+K` hotkey, filter tags, action shortcuts, row actions, files section, modal overlay or inline panel.
