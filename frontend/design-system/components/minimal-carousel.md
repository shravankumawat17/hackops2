# Minimal Carousel (`MinimalCarousel`)

Swipeable horizontal card carousel with previous/next controls, dot pagination, and layout animations.

- **Source Code**: [`minimal-carousel.tsx`](./minimal-carousel.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/minimal-carousel.json
  ```
- **Dependencies**: `motion, lucide-react`

---

## Features
- Clean minimalist card presentation
- Previous and next arrow buttons with disabled states
- Animated active dot indicators
- Responsive drag and swipe gestures

---

## Source & Import

```tsx
import MinimalCarousel from "@/components/ui/minimal-carousel";
```
