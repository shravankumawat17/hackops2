# Responsive Navbar (`Navigation5`)

Modern responsive header navbar with navigation menu dropdowns, feature badges, mobile sheet drawer, and auth buttons from Watermelon UI.

- **Source Code**: [`navigation-5.tsx`](./navigation-5.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/navigation-5.json
  ```
- **Dependencies**: `lucide-react, NavigationMenu, Sheet, Accordion primitives`

---

## Features
- Desktop navigation menu dropdowns with feature descriptions
- Mobile hamburger drawer using sheet primitives
- Status badges on navigation items
- Sign In / Get Started CTA buttons

---

## Source & Import

```tsx
import Navigation5 from "@/components/ui/navigation-5";
```
