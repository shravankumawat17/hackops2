# Tooltip Pagination (`Pagination8`)

Accessible pagination controls enhanced with floating tooltips on next/previous and page numbers from Watermelon UI.

- **Source Code**: [`pagination-8.tsx`](./pagination-8.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/pagination-8.json
  ```
- **Dependencies**: `Pagination, Tooltip primitives`

---

## Features
- Hover tooltips indicating next/prev page titles
- Clean accessible Radix/Shadcn pagination primitives
- Ellipsis for truncated page counts
- Theme-responsive active page indicator

---

## Source & Import

```tsx
import Pagination8 from "@/components/ui/pagination-8";
```
