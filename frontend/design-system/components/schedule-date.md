# Schedule Date Picker (`ScheduleDate`)

Date and time slot scheduling calendar with week/day view selectors, time chip buttons, and appointment booking UI.

- **Source Code**: [`schedule-date.tsx`](./schedule-date.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/schedule-date.json
  ```
- **Dependencies**: `framer-motion, lucide-react`

---

## Features
- Interactive date picker with selected day highlighting
- Available time slots grid
- Timezone indicator and selector
- Confirm booking action button

---

## Source & Import

```tsx
import ScheduleDate from "@/components/ui/schedule-date";
```
