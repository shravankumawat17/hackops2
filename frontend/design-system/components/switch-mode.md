# Switch Mode Theme Toggle (`SwitchMode`)

Polished theme toggle switch for Light, Dark, and System modes with animated sliding indicator pills.

- **Source Code**: [`switch-mode.tsx`](./switch-mode.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/switch-mode.json
  ```
- **Dependencies**: `motion, next-themes, react-icons`

---

## Features
- Triple option pill: Light, Dark, System
- Spring animated indicator layoutId transition
- Seamless integration with next-themes
- Compact and accessible

---

## Source & Import

```tsx
import SwitchMode from "@/components/ui/switch-mode";
```
