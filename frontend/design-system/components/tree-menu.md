# Tree Menu & File Tree (`TreeMenu`)

Collapsible hierarchical tree navigation menu with folder/file nesting, active selection highlighting, and indent lines.

- **Source Code**: [`tree-menu.tsx`](./tree-menu.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/tree-menu.json
  ```
- **Dependencies**: `motion, react-icons`

---

## Features
- Recursive nesting for directories and submenus
- Expand / collapse chevron animations with spring physics
- Custom node icons (folder, file, code, settings)
- Active item highlight and click event handling

---

## Source & Import

```tsx
import TreeMenu from "@/components/ui/tree-menu";
```
