# View On Map Modal (`ViewOnMap`)

Expandable card that morphs into a map location viewer with pin points, directions, and satellite toggle.

- **Source Code**: [`view-on-map.tsx`](./view-on-map.tsx)
- **Install Command**:
  ```bash
  npx shadcn@latest add https://registry.watermelon.sh/r/view-on-map.json
  ```
- **Dependencies**: `motion, lucide-react, react-icons`

---

## Features
- Smooth layoutId morph from thumbnail to interactive map view
- Location pin indicator with pulse animation
- Directions, share, and copy coordinates actions
- Fullscreen backdrop overlay

---

## Source & Import

```tsx
import ViewOnMap from "@/components/ui/view-on-map";
```
